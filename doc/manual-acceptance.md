# pi-orb 人工验收

本页只维护当前步骤。每次执行把 OS、键盘布局、实际依赖版本、表现和证据路径写入对应 evidence；是否支持及未验证范围只更新 [支持矩阵](./support-matrix.md)，不在这里再维护一套结果表。旧工具和旧驱动的记录保留在 Git 历史与阶段证据中。

## 0. 验证原则

成功必须有目标自身事件、内容读回或系统状态，工具返回 completed 不能代替成功。结果区分通过、失败、未验证和不适用；环境不满足时写明原因。单测、夹具、实际 Electron 与真实模型验证的范围分别记录。

只操作本次新建的丢弃式窗口、网页和文件。高权限窗口由验收者手动创建并明确授权。取消不回滚已投递事件；异常立即 Stop 或隐藏浮窗，检查按键与鼠标释放。

## 1. 前置条件

1. 平台和版本满足支持矩阵，执行产物确为本轮构建。
2. Pi Web 已可连接，模型支持工具调用；GUI 任务还需要图像能力与解锁的交互式桌面。
3. 源码验收按 [README](../README.md) 注册 Pi 插件并重启 Pi Web；个人安装包按 [安装文档](./personal-user-installation.md) 注册随包插件。
4. 浮窗选定专用工作区，确认模型和 Access。普通工作区不得新增 Orb 工具或提示。

### 1.1 工具装配

当前 GUI 工具为 `click`、`input_text`、`scroll`、`hotkey`、`long_press`、`drag`、`wait`、`long_wait`、`screenshot`、`open_in_browser`、`open_in_finder`、`list_apps`、`open_app`；后台使用 `code_agent`、`code_agent_status`、`code_agent_stop`。完整契约见 [参考工具集](./reference-toolset-transition.md)。

自动首帧应先于模型 GUI 动作出现在会话中。坐标使用最新截图的 0–1000 millifraction，动作后返回新图；不要求模型显式 observe、填写 observation id 或使用 batch。

## 3. A 组：真实键盘与唤醒

| 编号 | 操作 | 预期 |
|---|---|---|
| A1 | 其他应用前台时按唤醒快捷键 | 显示并聚焦浮窗 |
| A2 | 浮窗前台时再按快捷键 | 隐藏并撤权 |
| A3 | 浮窗可见但失焦时按快捷键 | 聚焦已有窗口；置顶导致遮挡前提无法构造时说明不适用 |
| A4 | 长按快捷键 | 只切换一次，松开后下次按键仍有效 |
| A5 | 连续两次单击托盘，间隔超过双击时间 | 显示、隐藏各一次 |
| A6 | 托盘菜单显式显示/隐藏 | 行为与文案一致，隐藏撤权 |
| A7 | 设置冲突快捷键后重新唤醒 | 显式报冲突，原快捷键可用 |
| A8 | 浮窗前台点击关闭按钮 | 隐藏并撤权 |
| A9 | 退出后由另一程序注册同一快捷键 | 原注册已释放 |
| A10 | 双 Alt、AltGr 与非 US 布局 | 双 Alt 只打开截图预览，普通文字输入不误触发 |
| A11 | 锁屏/解锁、休眠恢复后重复唤醒 | 无卡键；恢复不继承过期授权 |

## 4. B 组：截图分享

| 编号 | 操作 | 预期 |
|---|---|---|
| B1 | 普通丢弃窗口前台，双 Alt 或菜单截图 | 预览实际目标窗口，排除 Orb |
| B2 | 丢弃预览 | 不上传图片 |
| B3 | 重新预览并确认发送 | 图片只进入当前会话 |
| B4 | 捕获前关闭或移动目标窗口 | 按当前捕获合同拒绝或更新目标，结果与预览一致；不静默上传整屏 |
| B5 | 多显示器、不同 DPI、遮挡及高权限窗口分别截图 | 单独记录尺寸、目标、排除与拒绝行为 |
| B6 | 仅文本模型请求附图 | 明确拒绝图像，不静默发送 |

截图分享仍需预览确认，不以 Access grant 代替单张确认。

## 5. C 组：当前原生输入

| 编号 | 操作 | 预期 |
|---|---|---|
| C1 | 在丢弃目标上测试点击、双击、修饰键 | 目标自身事件与请求一致 |
| C2 | 聚焦文本框后 input_text，含中文与换行 | 精确文本读回，replace/submit 按参数生效 |
| C3 | scroll 与 hotkey | 目标收到正确滚动/键序列，动作后返回新图 |
| C4 | long_press/drag 途中 Stop、隐藏或断连 | 释放输入，无后续动作 |
| C5 | 模型思考后抢走焦点或替换目标 | 过期动作被拒，不能输入错误窗口 |
| C6 | 高权限与多屏目标 | 无自动提权；分别记录支持/拒绝情况，不能外推普通窗口结果 |
| C7 | 截图中指定控件，模型点击后再截图 | 首帧和动作后新图都存在，落点由目标自身日志证明 |

## 6. D 组：真实模型与后台任务

| 编号 | 任务 | 独立判据 |
|---|---|---|
| D1 | 多轮 GUI 任务及无图像模型 | 首帧策略正确，正常 idle 不清除手动 Access，图像不支持时明确处理 |
| D2 | open_in_browser 打开丢弃网页并操作 | 可见截图驱动动作，网页自身完成请求 |
| D3 | open_app 激活运行应用或冷启动新应用 | 返回实际前台新图，后续动作命中实际应用；慢启动不伪报已前置 |
| D4 | open_in_finder、screenshot 保存/复制 | 路径和文件内容读回；未明确导出时不写截图文件 |
| D5 | 跨应用继续操作，途中切换会话/工作区 | 动作不串会话，新旧草稿与上下文不混用，旧 grant 失效 |
| D6 | 目标滚动区域滚动 | wheel 与 scrollTop 变化；不是只看工具成功 |
| D7 | code_agent 完成、继续、停止及失败 | 独立 worker、owner 隔离、双空闲后单次通知；停止不再通知完成，失败全文一致 |
| D8 | 点击后输入指定文本 | 聚焦和输入各有新图，目标精确读回 |

当前探针入口为 `node evidence/p1-06/run-real-model-c7.mjs <场景>`，支持 `c7`、`d6-scroll`、`d8-type`、`browser`、`open-app`。后台脚本和隔离要求见 [P1-06 证据](../evidence/p1-06/README.md)。真实模型调用会使用已配置 provider。

## 7. 验收后

按 [贡献指南](../CONTRIBUTING.zh.md) 跑对应质量门禁，保留原始结果和失败记录。改动打包配置必须执行 `node evidence/p2-05/run-p2-05.mjs`，分别检查包内容与实际打包产物运行。执行结果写 evidence，当前结论同步支持矩阵，来源和适配理由写对应阶段记录。

## 8. 环境限制

多显示器/DPI、高权限窗口、真实键盘/锁屏/休眠、广泛跨应用及干净机需各自条件。单屏普通窗口的成功不能证明这些范围。macOS/Linux 未验证，不因 Windows 结果宣称支持。具体剩余范围只见支持矩阵。

## 9. E 组：干净机安装、升级与卸载

本机已有运行时的安装探针不代替干净用户账户、另一台机器或快照虚拟机验收，干净机与 SmartScreen 保持未验证直到有对应证据。使用本轮 `release/<version>/` 的安装器，开始前记录 Node/Pi/Pi Web 条件与是否已有 Orb。

| 编号 | 步骤 | 预期 |
|---|---|---|
| E1 | 双击安装包 | 可选目录、每用户安装、不要求 UAC 提权 |
| E2 | 自定义目录完成安装 | 开始菜单和桌面快捷方式有效 |
| E3 | 快捷方式及 Win+R 输入 pi-orb | 浮球启动，首次插件注册和工作区流程可完成；再次执行唤回同一窗口 |
| E4 | 检查应用条目与卸载命令 | 条目和安装目录一致 |
| E5 | 检查 HKCU 卸载信息与 App Paths | 路径指向实际 EXE，含空格/中文路径可用 |
| E6 | 覆盖升级 | 工作区、快捷键、模型、凭据和历史保留，旧授权不恢复 |
| E7 | 控制面板或安装目录卸载 | 程序/快捷方式/App Paths 清理，移除随包插件声明 |
| E8 | 卸载后检查数据与共享后端 | 工作区与 Pi 历史保留，Pi Web 服务、源码和其他插件不受影响 |
| E9 | 未签名安装器首次运行 | 记录 SmartScreen 实际提示与发布者信息；不禁用安全设置 |

不以本机构建成功、App Paths 登记或静默安装替代 E1–E9。未签名产物的提示依环境记录，不能预先写成必然出现。
